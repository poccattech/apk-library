# POCCAT – APK Downloads

Welcome to the official **POCCAT Android APK release repository**.

This repository is dedicated to distributing the latest Android APK versions of POCCAT.

### Download & Install

1. Go to the [Releases](../../releases) section.
2. Select the latest release.
3. Download the `.apk` file under **Assets**.
4. Open the downloaded file on your Android device and follow the installation instructions.

You may find the full installation guide here https://poccat.com/download?platform=android

**Note:** You may need to allow installation from unknown sources on your Android device.
